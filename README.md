# ElevenHouse — продукт

Интерфейс рабочего пространства астролога: клиенты, встречи, расчёты, заметки, переписки, услуги и учёт оплат. Самостоятельный фронтенд на React, TypeScript и Vite. Лендинг находится в отдельном проекте.

## Опубликованный сайт

https://vv-organization.github.io/elevenhouse-product/

## Запуск

Требуется Node.js 22.

```sh
npm ci
npm run dev
```

Проверки и сборка:

```sh
npm test
npm run build
npm run preview
```

Готовые статические файлы находятся в `dist/`. Пути к ресурсам относительные; навигация использует hash и работает внутри адреса GitHub Pages без серверных перенаправлений.

Это вымышленные данные для проверки интерфейса. Серверная авторизация, доставка писем и сообщений, приём платежей и расчётный движок не подключены. Код входа реализует локальный сценарий. Изменения хранятся в браузере и не синхронизируются между устройствами. Для подключения реальных пользователей требуется отдельный бэкенд.

На новом домене браузер создаст отдельное хранилище: изменения с localhost автоматически не переносятся. Вход с указанной почтой создаёт заполненный профиль при первом открытии.

## Деплой

Workflow `.github/workflows/deploy.yml` на каждом push в `main`:

1. Устанавливает зависимости через `npm ci`.
2. Запускает тесты и проверку TypeScript.
3. Собирает сайт.
4. Публикует `dist/` через GitHub Pages.

Pull request запускает проверки без публикации. Ручной запуск доступен через Actions → Check and deploy product → Run workflow. В Settings → Pages источник публикации — **GitHub Actions**. Дополнительные секреты для деплоя не нужны.

## Структура

- `product/` — исходники и тесты интерфейса.
- `product/assets/` — логотипы и локальные шрифты; сведения об авторах и лицензии сохранены рядом со шрифтами.
- `vite.config.ts` — независимая конфигурация сборки продукта.

Не добавляйте в публичный репозиторий реальные клиентские данные, ключи сервисов или токены. Файлы `.env` исключены из Git.
