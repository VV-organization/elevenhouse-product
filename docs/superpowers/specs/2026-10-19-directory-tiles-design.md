# Каталог «Все разделы»

Пользователь одобряет группировку, просит аккуратные карточки по приложенному референсу Behance. Переносим принцип: ровная сетка, контурные иконки в верхней части карточки, название внизу, достаточные внутренние отступы. Сохраняем текущие группы и все 23 маршрута. Не копируем сторонний бренд, рекламные блоки и onboarding sidebar.

Группы идут вертикально, карточки внутри каждой занимают равные колонки. На широком экране 3–5 карточек в зависимости от группы, на планшете/телефоне 2. Ночной синий/молочный фон, матовое золото иконок, тонкая граница, спокойный hover без сдвига. Названия не обрезаются. Карточка целиком является ссылкой, Tab и видимый focus поддержаны. Настройки и тарифы — компактный отдельный ряд.

Без подписей, повторяющих заголовки, без новых данных/зависимостей. Existing entrance motion анимирует группы. Hero и остальные рабочие экраны не меняются. Проверить dark/light, 1440/1024/390/320 px, все ссылки, keyboard, hover, отсутствие overflow. Изменения локальные, без публикации.
