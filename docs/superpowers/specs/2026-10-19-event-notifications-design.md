# Всплывающие уведомления

Пользователь подтвердил формат старого интерфейса: карточки справа снизу с кнопкой открытия оплаты или сообщения. Источник композиции — приложенный скриншот и исходный app/toast.jsx. Цвета и шрифт — действующая айдентика продукта: ночной синий, молочный, золото; оплата получает спокойный зелёный статус, сообщение — золотой.

До двух видимых карточек, постоянный крестик, явный CTA, без захвата фокуса и таймера исчезновения. Короткое появление opacity/translate, без движения при reduced motion. На mobile и невысоких экранах видна одна карточка, остальные ожидают в очереди; при открытом dialog скрыты и ждут закрытия. Demo dock находится вне iframe и не перекрывается.

Источник — существующие payments и conversations плюс связанные внешние сообщения. Оплата со статусом paid называется «Оплата отмечена», поскольку локальная запись не подтверждает банковское поступление. Сообщения — только входящие; прочитанные события не всплывают. Первое открытие показывает максимум последнее событие каждого типа. Последующие новые события стоят в очереди, максимум 20; вся история доступна через центр уведомлений. Исходный набор известных ID и очередь сохраняются отдельно для каждой практики; перезагрузка сохраняет ещё не закрытые карточки. Закрытие скрывает карточку, открытие также отмечает событие прочитанным.

Существующий useModuleState не синхронизирует независимых читателей: добавить уведомление после успешного сохранения и read-only hook для панели. Не менять реализацию всех модулей. Маршруты: paymentId открывает конкретную PaymentDetails; conversation выбирает правильный чат и работает уже внутри раздела сообщений.

Hero, зависимости, обычная сессия и demo isolation не меняются. Новые backend-подключения не входят в задачу. Commit/push/deploy не запрошены.
