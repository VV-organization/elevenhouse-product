# Переключатель экранов для демонстрации

Пользователь прямо попросил повторить нижнюю панель из предоставленного скриншота старого продукта для показа руководителю. Повторяем расположение и принцип переключения в существующей айдентике: ночной синий, молочный текст, матовое золото активного экрана. Восемь запрошенных режимов: регистрация специалиста, регистрация клиента, онбординг, заполненный кабинет, его мобильная версия, кабинет клиента, публичная страница и админка.

Вход по ?demo=1; выбранный экран в URL, перезагрузка и Back восстанавливают его. Обычный продукт без параметра не получает панель. Оболочка содержит настоящие компоненты продукта в отдельном iframe, поэтому мобильная ширина действительно включает media queries, а диалоги внутри экрана не закрывают переключатель. Меняется только текущий iframe; данные и черновики демонстрационных модулей сохраняются в отдельной области showcase. Состояние обычного аккаунта не изменяется. После перехода между режимами несохранённые поля регистрации начинают с начала; остальные черновики сохраняются существующими механизмами модулей.

Регистрация использует общий AuthPage и тестовый код 123456, клиентская версия имеет свой заголовок и приводит в кабинет клиента. Онбординг использует настоящий выбор первого действия и текущие подсказки в пустой демонстрационной практике. Кабинеты открываются с данными Анны/Марины. Публичная страница показывает PublicProfilePreview и позволяет перейти к записи в клиентском кабинете. Админка показывает демонстрационные записи, операции остаются подготовленными запросами.

Кнопка «Начать заново» сбрасывает только текущий демонстрационный экран. Закрытие возвращает обычное приложение. На мобильном панель прокручивается горизонтально, выбранная кнопка видна; у всех действий клавиатурный фокус. Прямые переходы и перезагрузка проверяются. Лендинг/Hero и его глобальные стили не меняются; в запросе перечислены восемь продуктовых экранов.
