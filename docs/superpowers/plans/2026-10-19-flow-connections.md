# Flow connections Implementation Plan

> Исполнение в текущей сессии, тесно связанные UI-задачи выполняются последовательно.

**Goal:** Вернуть читаемую схему воронки с соединениями из одобренного референса.
**Architecture:** Чистая модель графа поверх flowTargets, SVG-соединения и HTML-карточки, существующий FlowWorkspace остаётся владельцем данных и форм. Отдельный scoped CSS.
**Tech Stack:** React 19, TypeScript, SVG, CSS, Vitest, Playwright.

## Global Constraints

- Только product/ и документация продукта; без новых dependencies и изменений Hero/auth.
- Сохранять все текущие настройки, маршруты, черновики и проверку.
- Ночной синий, молочный, матовое золото; обе темы, 320–1440 px, клавиатура, reduced motion.
- Рабочая копия: deploy/elevenhouse-product, канонический remote VV-organization/elevenhouse-product.

## Задачи

- [x] Модель графа: product/state/flow-graph.ts и flow-graph.test.ts. Контракт buildFlowGraph(flow) -> nodes/edges/width/height; nodes имеют id,kind,x,y; edges from/to/branch. Вход определяется entryId, переходы flowTargets, конец синтетический, ошибочные цели видны и не становятся концом. Ранжировать DAG без обратных рёбер, возвраты выводить отдельной дугой. Тесты: ветвление и слияние, изменение порядка без изменения связей, ограниченный цикл, отсутствующая цель, остановка trace на approval.
- [x] Компонент product/modules/FlowGraph.tsx и flow-graph.css. SVG под HTML-карточками; обычные и подсвеченные кривые, расширение у карточки. Выбор, клавиатура, масштаб 50–150% и обзор всей схемы без нижнего ограничения, уместить, прокрутка. Конечный импульс только по рёбрам теста, без продолжения после согласования.
- [x] Интеграция communication-flows.tsx: переключатель Схема/Список, выбранный шаг и событие в инспекторе, палитра по кнопке, сохранённые поля и все методы изменения без дублирования. Смена выбора не сбрасывает черновик. Добавленный шаг выбирается, удалённый возвращает выбор к событию.
- [x] Проверки: npm test, npm run build в репозитории продукта; браузер вход member, редактирование, выбор, ветка, проверка/остановка, reload, обе темы, 1440/960/390/320, reduced motion и отсутствие ошибок. Снимки и сценарии в корневом artifacts/flow-connections-2026-10-19. Независимый review после реализации.
